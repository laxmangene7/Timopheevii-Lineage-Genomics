# Timopheevii-Lineage-Genomics
This repository contains the scripts and code used to analyze the genomic datasets generated for the project "Evolutionary dynamics of the ‘unsuccessful’ Timopheevii wheat lineage."
We assembled the genomes of _Triticum_ _timopheevii_ and _T_. _zhukovskyi_, analyzed whole-genome sequencing (WGS) data of T. timopheevii, and generated skim-seq data for both T. zhukovskyi and T. monococcum.

## Homoeologous exchange (HE) breakpoints vs Am/At similarity in *T. zhukovskyi* and *T. timococcum*

Code for calling dosage from sequence read depth, extracting breakpoints, and testing whether homoeologous exchange (HE) breakpoints between the At and Am subgenomes fall in windows of high Am–At sequence similarity (low k-mer variation) in natural *T. zhukovskyi* and in synthetic hexaploid generated by crossing *T. timopheevii* and *T. monococcum* (einkorn). The k-mer variation was computed with FastIBS.

Code, input read counts (`data/`), k-mer tables, the three run scripts and the final figure are in the folder [`HE_breakpoints/`](HE_breakpoints/). To replicate:

    cd HE_breakpoints
    python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
    bash run_timococcum.sh     # T. timococcum breakpoints, HE pairs and plots
    bash run_zhukovskyi.sh     # T. zhukovskyi breakpoints, HE pairs and plots
    bash run_merged.sh         # combined histogram and violin plot with statistics

Each script ends with a PASS/FAIL check of the manuscript numbers. See `HE_breakpoints/README.md` for details.

This analysis uses 100-kb read counts (HE_breakpoints/data/) and is independent of the 1-Mb bed files used for the coverage plots above.

**AI assistance**. Claude (Anthropic) was used to help write the code and documentation for the HE breakpoint analysis. The authors independently verified the code and results, including by checking breakpoints multiple times against read-depth coverage plots and an independent R-based analysis, and by reproducing the numbers from the raw read counts using the provided check scripts.
