# Homoeologous exchange (HE) breakpoints vs Am/At similarity (*T. timococcum*, *T. zhukovskyi*)

Code for calling dosage from sequence read depth, extracting breakpoints, and testing whether homoeologous exchange (HE) breakpoints between the At and Am subgenomes fall in windows of high Am–At sequence similarity (low k-mer variation) in natural *T. zhukovskyi* and in synthetic hexaploid *T. timococcum* generated by crossing *T. timopheevii* and *T. monococcum*. The k-mer variation was computed with FastIBS.

## Contents
| Path | Content |
|---|---|
| `data/all_plants_timococcum_100Kb.tsv.gz` | read counts per 100-kb bin, 88 *T. timococcum* plants (columns `sample`, `count`, `chrom`, `start_bp`) |
| `data/all_plants_zhukovskyi_100Kb.tsv.gz` | the same for 19 *T. zhukovskyi* plants |
| `data/kmer_windows/` | k-mer variation (k = 31) in 100-kb windows for Am (TA10622) and At (TA2804) |
| `code/` | Python scripts (see below) |
| `run_timococcum.sh`, `run_zhukovskyi.sh`, `run_merged.sh` | the three run scripts |
| `figures/` | final figure used in the manuscript |

Reads were mapped to a synthetic reference carrying the At (TA2804), Am (TA10622) and G subgenomes; the two species are independent populations that share only the reference.

## Run
```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
bash run_timococcum.sh      # T. timococcum: breakpoints, HE pairs, histogram, violin plot, per-plant plots  (about 15 min)
bash run_zhukovskyi.sh      # T. zhukovskyi: the same                                                      (about 5 min)
bash run_merged.sh          # combined histogram + violin plot and statistics from the two runs            (about 3 min)
```
Each script ends with `code/check_reproduction.py`, which prints PASS or FAIL for the key numbers of the manuscript (see below). Everything is written to `results/` (not stored on GitHub).

## What each run does
1. `call_dosage.py`: per-plant dosage (hidden Markov model on 100-kb read depth, calibrated on chromosomes 3G, 5G, 7G; minimum tract 3 Mb) and breakpoints.
2. `he_pipeline.py`: classifies breakpoints (HE, Non-HE structural, G-genome) and pairs Am and At breakpoints.
3. `filter_reliable_he.py`: removes unreliable calls and the HE-free centromeric interior.
4. `make_unique_pairs.py`: unique exact reciprocal Am/At pairs (with plant IDs) and HE-active ranges.
5. `hist_merged_species.py`: k-mer variation at breakpoint windows vs non-breakpoint windows in HE-active regions; histograms, violin plots, tests (Mann–Whitney U, chromosome-stratified permutation, local paired Wilcoxon and sign test, Cohen's d, Holm-adjusted pairwise tests).
6. `plot_plant_overview.py`: per-plant read depth with dosage axis and dotted lines at reliable HE breakpoints.

## Key outputs (in `results/<species>/` and `results/merged/`)
- `calls/breakpoints_all_plants.tsv`, `calls/qc_per_plant.tsv`
- `reliable/breakpoints_reliable.tsv`
- `pairs/HE_exact_reciprocal_pairs_unique.tsv` (unique pairs, plants listed), `pairs/HE_active_ranges.tsv`
- `merged/*_stats.tsv`, `merged/*_violin_tests.tsv`, final figure files

## Expected numbers
*T. timococcum*: 492 unique exact reciprocal HE pairs (663 in individual plants); reliable breakpoints 1,469 HE, 2,634 Non-HE structural, 701 G-genome.
*T. zhukovskyi*: 129 unique pairs (359 in individual plants); 923, 604, 129.
Merged: 616 pairs; mean k-mer variation 919 (Am) and 953 (At) at breakpoints vs 1,077 and 1,087 at non-breakpoint HE-active windows; Cohen's d −0.70 and −0.66.
Permutation p-values are random and differ slightly between runs (reported as P < 1e-4 with 10,000 permutations).

## Requirements
Python 3.10 or newer; pandas, numpy, scipy, openpyxl, matplotlib (`requirements.txt`). Tested with Python 3.13, pandas 3.1.1, scipy 1.18.1, matplotlib 3.11.2. Figures use TeX Gyre Heros (Helvetica-compatible) if installed.
